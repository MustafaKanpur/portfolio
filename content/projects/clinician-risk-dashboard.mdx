## Problem

Risk scores that clinicians can't interrogate don't get used. A black-box probability next to a
patient's name raises more questions than it answers: *why* is this patient high risk, and
compared to whom?

<Todo>expand the problem with the clinical context and who this is for.</Todo>

## Approach

- **Model selection.** Trained Logistic Regression, Random Forest, and XGBoost on Synthea
  synthetic EHR data and compared them on ROC-AUC. XGBoost led at 0.95.
- **Explainability.** Per-patient SHAP attributions show which features pushed each
  prediction up or down.
- **Context.** KMeans clustering builds peer cohorts, so a clinician can compare a patient
  with similar patients instead of a population average.
- **Plain language.** A FastAPI backend sends chart data to the Claude API, which returns a
  short summary a clinician can read in seconds.
